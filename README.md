# 👨🏻‍💻 Nathan Cruz
### 💼 Analista e Desenvolvedor de Sistemas | 🐍 Python • ⚗️ Flask • 🗄️ SQL

Desenvolvedor de sistemas com formação em **Análise e Desenvolvimento de Sistemas**, focado na criação de soluções práticas para problemas reais. Tenho interesse especial em **automação de processos, aplicações web e desktop, organização de dados** e ferramentas que simplifiquem rotinas.

Gosto de acompanhar o projeto além do código: entender a necessidade, estruturar a solução, pensar na experiência de uso e cuidar de aspectos como manutenção, documentação e distribuição.

## 🙋🏻‍♂️ Sobre mim

- 🧩 Desenvolvo aplicações principalmente com **Python**, **Flask** e **SQLAlchemy**.
- 🗃️ Tenho experiência prática com bancos de dados relacionais, especialmente **SQLite**, e fundamentos de SQL.
- 🖥️ Já trabalhei em projetos com fluxos de cadastro, relatórios para impressão, integração com webcam, empacotamento para Windows e mecanismos de atualização.
- 🛡️ Estudo continuamente boas práticas de arquitetura, testes automatizados, segurança e automação de entregas.
- 🤖 Também exploro aplicações de inteligência artificial para resolver problemas específicos.
- 🛠️ Gosto de transformar ideias em ferramentas úteis, priorizando clareza, organização e manutenção.

## 🚀 Projetos em destaque

### 🛂 [SISPORT — Sistema de Controle de Portaria](https://github.com/NathanCruzOficial/SISPORT)
Aplicação para registro e acompanhamento de visitantes, com fluxo de cadastro guiado, registro de entrada e saída, captura de fotografia e relatórios A4. O projeto também explora migrações de banco de dados, logs, empacotamento e atualização da aplicação no Windows.

**Tecnologias:** Python · Flask · SQLAlchemy · SQLite · JavaScript

### 📊 [Dashboard BDA](https://github.com/NathanCruzOficial/dashboard_bda)
Projeto voltado à organização e visualização de informações em um painel, com configuração da aplicação e suporte a banco de dados.

### 📄 [Gerador de Contratos](https://github.com/NathanCruzOficial/Gerar-Contrato)
Projeto de automação documental com foco na geração de contratos a partir de modelos e dados preenchidos.

### 🎖️ [GenNoGU — Gerador de Nomes de Guerra](https://github.com/NathanCruzOficial/GenNoGU)
Aplicação desktop para gerar nomes de guerra, explorando também a ideia de distribuição de versões por meio de releases.

### 📖 [Verbum — Assistente de Estudos Bíblicos](https://github.com/NathanCruzOficial/Projeto_Imersao_IA_AluraGoogle)
Experimento com IA generativa para ajudar usuários a explorar versículos por sentimentos, temas e perguntas, desenvolvido durante a Imersão IA da Alura com o Google.

## 🧠 Como penso desenvolvimento

- 🎯 **Resolver o problema certo:** entender a necessidade antes de escolher a tecnologia.
- 🧱 **Construir com organização:** buscar clareza, modularidade e separação de responsabilidades.
- ⚙️ **Automatizar o repetitivo:** transformar processos manuais em ferramentas úteis.
- 🔍 **Cuidar dos detalhes:** considerar experiência de uso, manutenção e documentação.
- 📚 **Aprender construindo:** testar ideias, registrar decisões e evoluir a cada projeto.
